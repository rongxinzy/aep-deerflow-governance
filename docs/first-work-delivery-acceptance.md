# 首次开通到第一份成果：业务闭环验收

日期：2026-10-15。沿用现有“消息、我的搭档、组织”入口、视觉与头像，不发布生产应用。

## 本轮业务路径

普通员工登录 → UI 自动创建首位搭档及个人 microVM → 准备状态自动更新 →
从工作现场交办订单核查 → 真实模型发现登录页并请求人工接管 →
用户在远程浏览器输入验证码、归还 → 原任务重新观察登录后的页面 →
生成并登记 Markdown 报告 → 前端预览和下载 →
重新登录 → 添加第二位搭档 → 同一云电脑重建后原任务与报告仍可读取。

没有通过脚本预建 PersonalWorkspace，也没有手工补写其 spec。
测试准备仅建立隔离基础设施和 AEP 普通用户；业务动作走真实 UI。

## 改动与边界

- UI：首次开通显示准备步骤，准备期间不提前连接搭档会话；轮询真实工作区状态，
  可用后自动切换。创建失败后允许重新发起；已有工作区继续复用。
  任务详情展示搭档请求用户处理的原因，避免重复显示等待说明。
- Pi Durable：浏览器工具新增 request_human。等待状态持久化，旧执行令牌失效；
  接管版本号跨进程重启保留。空闲浏览器不能解除“尚未处理”的请求，
  新接管结束后才重新观察并恢复原任务。暂停、取消不会因归还而自动撤销。
  租约到期只触发重新观察，不证明用户完成了登录。
- 节点代理：自动生成的工作区名称原先直接拼为 TAP 名称，超过 Linux 15 字节限制，
  首次 VM 无法启动。短名称保持兼容，长名称使用稳定摘要；创建、FORWARD 规则、
  删除和孤儿清理统一使用同一名称。启动早期失败现在写入可见失败状态，
  系统仍会重试，恢复后清空失败说明。
- 此轮没有实现多用户节点容量准入或跨节点迁移，也没有改动现有头像生成逻辑。

## 隔离环境

- 命名空间 cloud-qa-first-work；真实 Kubernetes API、namespace-scoped Operator、
  Portal、AEP/PostgreSQL/对象存储临时实例。
- 独立 node agent 进程、hostPath、18800–18809 端口、192.168.242.0/24 网段，
  使用 Firecracker、Xvfb、Chromium 和一次性桌面模板 qa-first-work。
  Harbor/DaemonSet 的真实分发已由上一轮验收；本轮不重复声称验证新的镜像发布。
- 模型使用实际 Higress 路由上的 glm-4.6，非确定性模型替身。
  页面为一次性订单台账，包含仅登录后可见的随机核查编号。
  报告必须包含该编号及订单、客户、数量和交付日期，防止把泛化回复当作实际读取。
- 共享 OpenViking 当时 CrashLoop（索引元数据加载失败），其服务没有可用 endpoint。
  未修改生产实例；在测试命名空间用空数据目录启动同版本 OpenViking，
  使用独立 root key，并让 Operator 自动创建搭档记忆身份。
  这验证了开户身份发放，不代表长期记忆检索已完成业务验收。

## 可复用验收入口

zhiyuanBotUI 的 verify/first-work-delivery.mjs。
运行前构建 web，提供以下环境变量（口令通过环境/受保护文件注入，不写进命令历史）：

- WORKPLACE_ACCEPTANCE_REAL=isolated
- AEP_BASE_URL、PORTAL_BASE_URL：隔离 AEP 与 Portal
- WORKPLACE_ACCEPTANCE_USER、WORKPLACE_ACCEPTANCE_PASSWORD：尚无工作区的普通员工
- WORKPLACE_ACCEPTANCE_SITE：一次性台账站点
- WORKPLACE_SITE_CODE、WORKPLACE_REPORT_PROOF：台账验证码与仅登录后可见的核查编号
- WORKPLACE_ACCEPTANCE_OUTPUT：截图与结果目录，默认 /tmp/first-work-evidence

脚本不拦截 API。所有用户侧写操作从 UI 发起，API 仅用于读取实际状态与结果断言。
业务站点是验收夹具，不能将通过结果外推成任何第三方企业站点的接入证明。

## 发布顺序

合并与发布分开。后续获准发布时，先节点代理，再包含新 Gateway/搭档代码的桌面模板，
最后 UI。旧 Gateway 缺少接管版本号时，主动接管请求返回升级提示，
不会把浏览器空闲误当作用户已完成操作。存量短 TAP 名称不变，
此前无法创建的长名称现在可正常开通。

## 清理

完成验收后，通过 PersonalWorkspace finalizer 删除两轮测试 VM 与记忆用户；
删除测试命名空间及其 OpenViking 空数据实例；停止临时 AEP、Portal、Operator、
node agent 和台账网站；删除临时数据库/对象存储容器、模板与工作区磁盘、
测试凭据和 kubeconfig，关闭本地 SSH 转发。复核测试 TAP、NAT 和 FORWARD 规则均已移除。
为传输公开测试基底而临时增加的单来源端口规则与 HTTP 服务也已移除。
生产应用、共享 OpenViking 数据及配置均未修改。
